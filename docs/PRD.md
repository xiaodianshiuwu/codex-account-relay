# Codex Relay 产品定义

仅支持 macOS 14+ 原生 SwiftUI App。统一管理多账号接力和原聊天额度守护；保留历史 Tk/其他平台源码，不恢复发布。

- 多账号：隔离保存凭据、刷新额度、预检、原子切换、备份和失败回滚。真实切换需用户独立启用 ChatGPT 重启许可。手动确认页可明确选择切号后续跑及提示词，与自动接力共用原聊天回执链路；仅手动明确选择时允许继续用户已中断的聊天。
- 自动接力：App 运行期间按用户配置检查，读取最新 auto.json；关闭后停止新操作。阈值、间隔、策略、提示词和目标聊天均可配置。空提示只切换；非空提示必须明确指定本机聊天。低额度运行中先取得原轮次中断回执，切号后等待原聊天加载，验证原模型、目录与权限，通过桌面原聊天接口发送文字；只有收到新轮次 ID 才记成功，禁止猜测最近聊天或另开 CLI 执行。
- 额度守护：集成本机已有 2.2 后端，在统一原生页面选择本机/SSH 原聊天；小时剩余默认 ≤5% 中断、≥10% 恢复后发送自定义文字。周额度仅显示，服务明确拒绝仍等待。无需切号、退出或重启 ChatGPT。
- 守护默认不开启；开始后独立进程运行，退出 Relay 后仍有效，停止监控不结束正在执行的任务。沿用原聊天、模型、目录和权限，不自动响应审批；操作结果未知时不重复发送。
- 检查间隔为任意有限正数；无业务次数上限，提示词不设任意长度上限。协议帧容量及操作超时属于技术边界。
- 共用已存在的 CodexDesktopGuard 记录目录，支持环境变量隔离；不覆写旧项目及其运行记录。
- 后端采用固定在 App 内的独立运行时目录，随 App 签名；不在每次调用时临时解包 Python 原生库，不依赖用户的 Python。
- 四语言界面、浅深主题；新入口与错误可见，保存失败明确显示。

验收：隔离凭据/伪进程验证真实读写与回滚链路，守护本机/SSH 状态机及回执测试，Swift 后端桥接与设置测试，打包后端与 App 自检及签名检查。真实账号切换、业务聊天中断、自然重置和实际发送没有执行时必须明确标注。用户当前工作期间禁止重启 ChatGPT。
